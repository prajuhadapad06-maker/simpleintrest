Simple Interest Calculator

Project Description

This project is a simple Python program used to calculate Simple Interest.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Technologies Used

- Python 3
- Git
- GitHub

Program File

"Simple_interest.py"

How to Run

1. Install Python.
2. Open the project folder.
3. Run the command:

python Simple_interest.py

Features

- Accepts principal amount.
- Accepts rate of interest.
- Accepts time period.
- Calculates simple interest.
